Séance 1 : Bienvenue en TIM

Cette première heure va nous permettre de faire connaissance, de comprendre comment fonctionneront les cours de TIM cette année et de voir ce que vous savez déjà faire avec un ordinateur. Il ne s'agit pas d'un contrôle : l'objectif est simplement de savoir d'où nous partons.

1. Bienvenue en TIM

En BTSA ACS'AGRI, les Technologies Informatiques et Multimédia ne servent pas uniquement à apprendre à utiliser un ordinateur.

Elles vont notamment vous permettre de :

  • collecter et organiser des données professionnelles ;
  • traiter et analyser des informations ;
  • utiliser un tableur efficacement ;
  • produire des documents professionnels ;
  • représenter des informations sous forme de tableaux, graphiques ou schémas ;
  • utiliser des outils numériques professionnels ;
  • rechercher et vérifier des informations ;
  • transformer des données en informations utiles pour prendre une décision.

Le but n'est donc pas de devenir informaticien, mais de savoir utiliser efficacement le numérique dans votre futur métier.

2. Faisons connaissance

Avant de commencer, nous allons rapidement faire un tour de table.

Présentez-vous en indiquant :

  • votre prénom ;
  • le type d'exploitation ou de structure que vous connaissez le mieux ;
  • votre projet professionnel actuel, même s'il n'est pas encore totalement défini ;
  • un logiciel ou un outil numérique que vous utilisez régulièrement ;
  • une chose que vous aimeriez savoir faire avec un ordinateur mais que vous ne maîtrisez pas encore.

3. Comment fonctionneront les cours ?

Les séances de TIM seront principalement basées sur la pratique.

Quelques règles seront communes à presque toutes les séances :

  • vous travaillerez le plus souvent directement sur ordinateur ;
  • vous créerez votre document de travail dès le début de la séance ;
  • ce document pourra servir à la fois de cours, de brouillon, d'espace de test et de compte rendu ;
  • vous avez le droit d'essayer, de vous tromper, d'effacer et de recommencer ;
  • l'objectif est de comprendre ce que vous faites et non simplement de reproduire une procédure ;
  • les activités seront autant que possible liées à des situations agricoles ou professionnelles ;
  • un fichier sera généralement rendu à la fin de la séance.

Votre travail sera principalement observé à travers votre implication, votre progression, votre autonomie et les productions réalisées.

4. Bien nommer et ranger son travail

Une partie importante du travail numérique consiste simplement à pouvoir retrouver facilement ses fichiers.

Dans votre espace personnel, créez un dossier :

TIM_BTS2_ACSAGRI

Dans ce dossier, créez un sous-dossier :

S01

Les fichiers de cette séance devront être enregistrés dans ce dossier.

Lorsque le nom d'un fichier est imposé dans une activité, respectez-le exactement.

5. Petit diagnostic : que savez-vous déjà faire ?

Vous allez maintenant réaliser quelques petites missions. Elles ne sont pas notées comme un contrôle.

L'objectif est de permettre au professeur de repérer ce que vous maîtrisez déjà et ce que nous devrons retravailler ensemble.

Travaillez avec ce que vous savez faire actuellement. Si vous ne savez pas réaliser une action, passez simplement à la suivante.

Mission 1 : créer un document

Ouvrez LibreOffice Writer et créez un document nommé :

BTS2_S01_NOM_Prenom.odt

Dans ce document :

  1. Ajoutez le titre Mon profil numérique.
  2. Écrivez quelques lignes pour présenter votre parcours et votre projet professionnel.
  3. Ajoutez une liste à puces contenant au moins trois logiciels ou services numériques que vous connaissez.
  4. Ajoutez un sous-titre Mes compétences numériques.
  5. Créez le tableau suivant et complétez-le.
Compétence À l'aise Je me débrouille À apprendre
Organiser mes fichiers et dossiers
Utiliser un traitement de texte
Utiliser un tableur
Créer des formules de calcul
Créer un graphique
Rechercher une information fiable
Partager ou transmettre un document

Indiquez votre niveau en plaçant simplement un X dans la colonne correspondante.

Mission 2 : mettre en forme un document

Sans modèle fourni, essayez de rendre votre document agréable et facile à lire.

Vous pouvez notamment utiliser :

  • des styles de titres ;
  • du gras ou de l'italique ;
  • des alignements ;
  • des couleurs avec modération ;
  • une mise en forme du tableau.

Le résultat doit rester sobre et professionnel.

Mission 3 : exporter un document

Lorsque votre document est terminé, essayez de l'exporter également au format PDF.

Vous devez alors avoir dans votre dossier :

  • BTS2_S01_NOM_Prenom.odt
  • BTS2_S01_NOM_Prenom.pdf

Mission 4 : quelques manipulations avec un tableur

Ouvrez LibreOffice Calc et créez un fichier nommé :

BTS2_S01_Diagnostic_NOM_Prenom.ods

Reproduisez le tableau suivant :

Parcelle Surface (ha) Production (t)
Parcelle A4,228,5
Parcelle B6,841,3
Parcelle C3,525,1
Parcelle D7,144,8

Essayez ensuite, sans consigne supplémentaire, de :

  1. calculer automatiquement la surface totale ;
  2. calculer automatiquement la production totale ;
  3. calculer la production moyenne ;
  4. ajouter une colonne permettant de calculer la production par hectare ;
  5. mettre le tableau en forme pour qu'il soit facilement lisible.

Si vous savez faire davantage, vous pouvez essayer de créer un graphique représentant les productions des quatre parcelles.

6. Ce que le professeur observe

Pendant cette activité, le professeur ne cherche pas seulement à savoir si vous obtenez le bon résultat.

Il observe également :

  • votre manière d'organiser vos fichiers ;
  • votre autonomie ;
  • votre aisance avec les logiciels ;
  • votre capacité à chercher une solution ;
  • les outils que vous connaissez déjà ;
  • les difficultés qui devront être retravaillées cette année.

7. Avant de passer à la suite

Enregistrez tous vos fichiers dans votre dossier S01.

Vérifiez que vous êtes capable de les retrouver et de les ouvrir.

La deuxième partie de la séance nous permettra de commencer à travailler sur l'un des éléments les plus importants en TIM pour un futur professionnel agricole : transformer des données en informations utiles pour prendre une décision.

Séance 2 : De la donnée brute à la décision

Dans une entreprise agricole, collecter des données ne sert à rien si elles ne permettent pas de comprendre une situation et de prendre une décision. Aujourd'hui, vous allez travailler comme si vous deviez analyser rapidement les données d'un système fourrager.

1. Votre document de travail

Ouvrez LibreOffice Calc et créez immédiatement un nouveau classeur.

Enregistrez-le sous le nom :

BTS2_ACSAGRI_S02_NOM_Prenom.ods

Créez quatre feuilles et renommez-les :

  • Profil
  • Donnees
  • Analyse
  • Bilan

Ce fichier est votre espace de travail. Vous pouvez tester, vous tromper, corriger et recommencer. Il devra être rendu à la fin de la séance.

2. Faisons connaissance

Dans la feuille Profil, répondez brièvement aux questions suivantes :

  1. Dans quel type d'exploitation ou de structure avez-vous réalisé votre dernier stage ?
  2. Quelles productions agricoles connaissez-vous le mieux ?
  3. Quels logiciels professionnels agricoles avez-vous déjà utilisés ?
  4. Comment évaluez-vous votre niveau sur Calc ou Excel : débutant, intermédiaire ou avancé ? Justifiez en une phrase.
  5. Quelle compétence informatique aimeriez-vous réellement maîtriser à la fin de cette année ?

4. Peut-on faire confiance à ces données ?

Avant de réaliser le moindre calcul, observez attentivement le tableau.

Repérez au moins trois éléments pouvant poser problème lors d'un traitement informatique.

Dans la feuille Donnees, ajoutez une colonne intitulée Observation et indiquez les problèmes détectés.

Important : ne corrigez jamais une donnée en inventant une valeur. Si une information semble incorrecte mais que vous ne connaissez pas la bonne valeur, signalez-la.

5. Préparer les données

Dans la feuille Analyse, créez une version exploitable du tableau.

Votre tableau doit être :

  • correctement structuré ;
  • lisible ;
  • cohérent dans la manière d'écrire les catégories ;
  • compatible avec les calculs que vous allez effectuer.

Les données dont la fiabilité est douteuse doivent rester clairement identifiables.

6. Transformer les données en indicateurs

Ajoutez les colonnes nécessaires pour calculer automatiquement, pour chaque parcelle :

  • le rendement en tonnes de matière sèche par hectare ;
  • le coût des intrants par hectare ;
  • le temps de travail par hectare ;
  • la quantité d'azote par hectare lorsque la donnée est disponible.

Les résultats doivent être obtenus avec des formules. Aucun résultat calculé manuellement puis saisi dans le tableau ne sera accepté.

7. Interroger les données

Utilisez les outils de tri et de filtre du tableur pour répondre aux questions suivantes dans la feuille Bilan :

  1. Quelles sont les trois parcelles présentant le meilleur rendement calculable ?
  2. Quelle parcelle présente le coût d'intrants par hectare le plus faible ?
  3. Quelles parcelles semblent demander le plus de temps de travail par hectare ?
  4. Quelle donnée du tableau vous empêche de réaliser une analyse totalement fiable ?
  5. Quelles informations supplémentaires demanderiez-vous à l'exploitant avant de lui proposer une décision ?

8. Faire parler les données

Réalisez au moins un graphique pertinent permettant de comparer les parcelles.

Vous êtes libre du type de graphique utilisé, mais vous devez pouvoir expliquer pourquoi il est adapté à l'information que vous souhaitez montrer.

Ajoutez :

  • un titre clair ;
  • les unités nécessaires ;
  • une présentation permettant une lecture rapide.

9. De la donnée à la décision

Dans la feuille Bilan, rédigez une conclusion de quelques lignes répondant à la question suivante :

Pourquoi la qualité des données est-elle aussi importante que les calculs réalisés pour aider un agriculteur à prendre une décision ?

Votre réponse doit s'appuyer sur ce que vous avez rencontré pendant la séance.

10. Avant de rendre

Enregistrez une dernière fois votre fichier sous le nom :

BTS2_ACSAGRI_S01_NOM_Prenom.ods

Déposez ensuite votre fichier dans l'espace indiqué par le professeur.

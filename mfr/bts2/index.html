Pourquoi allons-nous travailler cela ?

Cette année, vous allez utiliser différents outils numériques pour traiter des données, produire des documents et analyser des situations professionnelles.

À quoi cela va-t-il vous servir ?

  • présenter clairement une information ;

1. Comprendre le rôle des TIM

En BTSA ACS'AGRI, les Technologies Informatiques et Multimédia ne servent pas simplement à « savoir utiliser un ordinateur ».

Elles permettent notamment de :

  • collecter et organiser des données professionnelles ;
  • traiter et analyser des informations ;
  • utiliser efficacement un tableur ;
  • produire des documents professionnels ;
  • présenter les résultats sous forme de tableaux ou graphiques ;
  • rechercher et vérifier une information ;
  • utiliser des outils numériques pour aider à comprendre une situation et prendre une décision.

Le but n'est donc pas de devenir informaticien. Le but est de savoir choisir et utiliser correctement un outil numérique lorsque vous en avez besoin dans votre activité professionnelle.

2. Faisons connaissance

Avant de travailler ensemble, il est utile de connaître un peu votre parcours et votre rapport au numérique.

Présentez-vous rapidement en indiquant :

  • votre prénom ;

  • un logiciel ou un outil numérique que vous utilisez régulièrement ;
  • une chose que vous aimeriez savoir faire avec un ordinateur mais que vous ne maîtrisez pas encore.

3. Comment fonctionneront les cours ?

Les séances de TIM seront principalement basées sur la pratique.

Votre travail sera observé à travers votre implication, votre progression, votre autonomie et la qualité de vos productions.

Séance 2 : Peut-on faire confiance aux données ?

Durée prévue : environ 1 heure

Notions et compétences travaillées

  • qualité et fiabilité d'une donnée ;
  • donnée manquante, donnée suspecte et donnée incohérente ;
  • standardisation des données ;
  • construction d'un indicateur ;
  • formules simples dans un tableur ;
  • comparaison de parcelles de tailles différentes.

Pourquoi allons-nous travailler cela ?

Dans une exploitation agricole, de nombreuses données peuvent être enregistrées : surfaces, productions, coûts, temps de travail, quantités d'intrants...

Mais un ordinateur ne sait pas automatiquement si une valeur est correcte.

Si une donnée est fausse, une formule parfaitement correcte peut produire un résultat faux.

À quoi cela va-t-il vous servir ?

Dans votre futur métier, vous pourrez recevoir des données provenant :

  • d'un logiciel de gestion ;
  • d'un salarié ;
  • d'un capteur ;
  • d'un conseiller ;
  • d'un fichier transmis par un partenaire ;
  • ou de vos propres relevés.

Avant de prendre une décision à partir de ces données, vous devrez savoir repérer les valeurs douteuses et construire des indicateurs permettant de comparer correctement les situations.

Séance 3 : Faire repérer automatiquement les situations à surveiller

Durée prévue : environ 1 heure

Notions et compétences travaillées

  • fonction logique SI ;
  • condition vraie / condition fausse ;
  • objectif ou seuil de comparaison ;
  • référence relative et référence absolue ;
  • automatisation d'une règle simple dans un tableur ;
  • utilisation d'un indicateur pour faire apparaître un point de vigilance.

Pourquoi allons-nous travailler cela ?

Lors de la séance précédente, vous avez calculé des indicateurs comme le coût des intrants par hectare ou le temps de travail par hectare.

Ces indicateurs sont utiles, mais il faut encore les lire un par un pour repérer les valeurs importantes.

Lorsque le nombre de parcelles augmente, cette méthode devient lente et peut provoquer des oublis.

Nous allons donc demander au tableur de repérer automatiquement les valeurs qui dépassent un objectif fixé.

À quoi cela va-t-il vous servir ?

Ce principe est utilisé dans de nombreux outils professionnels :

  • faire apparaître un coût dépassant un objectif ;
  • signaler un stock trop faible ;
  • repérer une valeur hors d'une plage attendue ;
  • identifier automatiquement des éléments nécessitant une vérification ;
  • construire progressivement un outil d'aide à la décision.

1. Reprendre les données fiables

2. Passer d'un indicateur à une règle

Nous avons maintenant des indicateurs fiables.

Mais un indicateur ne dit pas automatiquement s'il faut y porter attention.

Pour l'exercice, l'exploitant fixe l'objectif interne suivant :

Attention : 400 €/ha est une valeur fictive choisie uniquement pour apprendre à construire l'outil. Ce n'est pas une norme agricole.

Nous pouvons traduire cette règle en langage courant :

SI le coût par hectare dépasse 400 €, ALORS afficher « À surveiller », SINON afficher « OK ».

Dans la feuille Analyse, ajoutez une nouvelle colonne nommée :

Alerte coût

Avant d'utiliser Calc, complétez dans votre tête :

  • condition : ................................................................................................................
  • si la condition est vraie : ................................................................................................................
  • si la condition est fausse : ................................................................................................................

3. Traduire la règle dans Calc

La fonction SI permet au tableur de choisir entre deux résultats selon qu'une condition est vraie ou fausse.

Sa structure générale est :

=SI(condition;résultat_si_vrai;résultat_si_faux)

Si votre coût par hectare se trouve en I2, essayez de construire la formule permettant d'afficher :

  • À surveiller si I2 dépasse 400 ;
  • OK dans le cas contraire.
Indice 1

Commencez par écrire uniquement la condition : est-ce que I2 est supérieur à 400 ?

Indice 2

Utilisez la structure =SI(condition;"À surveiller";"OK").

Indice 3

Une formule possible est =SI(I2>400;"À surveiller";"OK").

4. Pourquoi ne pas laisser 400 directement dans la formule ?

Notre formule fonctionne.

Mais imaginons que l'exploitant modifie son objectif et décide de passer de 400 à 450 €/ha.

Si la valeur 400 est écrite dans de nombreuses formules, il faudra toutes les modifier.

Nous allons donc séparer :

  • la règle de calcul ;
  • la valeur du paramètre.

Créez une nouvelle feuille nommée Parametres.

Créez le tableau suivant :

Coût intrants maximum 400 €/ha

Q1 : Quel est l'intérêt d'écrire 400 une seule fois dans une feuille Parametres ?

Indice 1

Imaginez que le seuil change demain.

Indice 2

Comparez : modifier dix formules ou modifier une seule cellule.

Indice 3

Une valeur centralisée facilite la mise à jour du fichier et limite les risques d'oublier une formule.

5. Faire pointer la formule vers le paramètre

Nous allons maintenant remplacer le nombre 400 dans la formule par la cellule contenant ce paramètre.

Mais une difficulté apparaît : lorsque nous recopions une formule vers le bas, Calc déplace normalement les références de cellules.

Par exemple :

  • I2 devient I3 sur la ligne suivante ;
  • puis I4, etc.

C'est utile pour le coût de chaque parcelle.

En revanche, notre cellule contenant 400 doit rester toujours la même.

Pour bloquer une référence, on utilise les signes $.

Une référence comme :

$B$2

est appelée une référence absolue.

Modifiez votre formule afin qu'elle utilise la cellule de la feuille Parametres contenant 400.

Indice 1

La cellule contenant le coût maximum doit rester identique lorsque vous recopiez la formule.

Indice 2

Utilisez les signes $ devant la colonne et devant le numéro de ligne du paramètre.

Indice 3

Si le 400 se trouve en B2 de Parametres, la comparaison peut utiliser $Parametres.$B$2.

21. Les erreurs classiques à éviter au CCF

  • créer un graphique avant de savoir ce que l'on veut montrer ;
  • sélectionner des colonnes sans rapport avec la question ;
  • mélanger plusieurs unités très différentes sur un même axe sans réfléchir ;
  • oublier le titre ;
  • oublier l'unité ;
  • mettre toutes les données « parce qu'elles sont disponibles » ;
  • utiliser un graphique en secteurs pour une évolution dans le temps ;
  • utiliser une courbe pour des catégories qui n'ont pas d'ordre ;
  • confondre une association visible avec une relation de cause à effet.

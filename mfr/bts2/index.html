Séance 1 : Bienvenue en TIM

Cette première heure va nous permettre de faire connaissance, de comprendre comment fonctionneront les cours de TIM cette année et de voir ce que vous savez déjà faire avec un ordinateur. Il ne s'agit pas d'un contrôle : l'objectif est simplement de savoir d'où nous partons.

1. Bienvenue en TIM

En BTSA ACS'AGRI, les Technologies Informatiques et Multimédia ne servent pas uniquement à apprendre à utiliser un ordinateur.

Elles vont notamment vous permettre de :

  • collecter et organiser des données professionnelles ;
  • traiter et analyser des informations ;
  • utiliser un tableur efficacement ;
  • produire des documents professionnels ;
  • représenter des informations sous forme de tableaux, graphiques ou schémas ;
  • utiliser des outils numériques professionnels ;
  • rechercher et vérifier des informations ;
  • transformer des données en informations utiles pour prendre une décision.

Le but n'est donc pas de devenir informaticien, mais de savoir utiliser efficacement le numérique dans votre futur métier.

2. Faisons connaissance

Avant de commencer, nous allons rapidement faire un tour de table.

Présentez-vous en indiquant :

  • votre prénom ;
  • le type d'exploitation ou de structure que vous connaissez le mieux ;
  • votre projet professionnel actuel, même s'il n'est pas encore totalement défini ;
  • un logiciel ou un outil numérique que vous utilisez régulièrement ;
  • une chose que vous aimeriez savoir faire avec un ordinateur mais que vous ne maîtrisez pas encore.

3. Comment fonctionneront les cours ?

Les séances de TIM seront principalement basées sur la pratique.

Quelques règles seront communes à presque toutes les séances :

  • vous travaillerez le plus souvent directement sur ordinateur ;
  • vous créerez votre document de travail dès le début de la séance ;
  • ce document pourra servir à la fois de cours, de brouillon, d'espace de test et de compte rendu ;
  • vous avez le droit d'essayer, de vous tromper, d'effacer et de recommencer ;
  • l'objectif est de comprendre ce que vous faites et non simplement de reproduire une procédure ;
  • les activités seront autant que possible liées à des situations agricoles ou professionnelles ;
  • un fichier sera généralement rendu à la fin de la séance.

Votre travail sera principalement observé à travers votre implication, votre progression, votre autonomie et les productions réalisées.

4. Découvrir les références absolues

Dans une formule, une référence comme B2 est généralement une référence relative : elle se déplace lorsque la formule est recopiée.

Une référence comme $B$2 est une référence absolue : elle reste fixée sur la même cellule.

Lorsque vous recopierez vos formules d'alerte, les cellules contenant les paramètres ne devront pas changer.

4. Découvrir le format CSV

Un format très courant pour échanger des données tabulaires est le CSV.

CSV signifie Comma-Separated Values, mais le séparateur utilisé n'est pas obligatoirement une virgule. Un point-virgule, une tabulation ou un autre caractère peuvent également être employés.

Dans un fichier CSV :

  • une ligne correspond généralement à un enregistrement ;
  • les champs sont séparés par un caractère défini ;
  • le fichier contient essentiellement les données, sans la richesse de présentation d'un classeur Calc.

Source : LibreOffice – Import et export de fichiers CSV.

Ressource : LibreOffice – Import et export de données dans Base.

Lorsque votre feuille INTERVENTIONS est prête :

  1. activez la feuille INTERVENTIONS ;
  2. choisissez Fichier → Enregistrer sous ;
  3. sélectionnez le type Texte CSV (.csv) ;
  4. nommez le fichier interventions_NOM_Prenom.csv ;
  5. cochez si nécessaire Éditer les paramètres du filtre ;
  6. choisissez UTF-8 comme jeu de caractères ;
  7. utilisez le point-virgule comme séparateur de champ ;
  8. utilisez le guillemet double " comme séparateur de texte.

Attention : lors d'un export CSV, seule la feuille active est exportée et la mise en forme ou les autres feuilles du classeur ne sont pas conservées.

    8. UTF-8 : pourquoi parler de codage des caractères ?

    Les caractères sont enregistrés dans un fichier sous forme de nombres. Il faut donc que le logiciel sache comment interpréter ces nombres pour afficher les bons caractères.

    Dans notre fichier apparaissent notamment :

    • Préparation ;
    • coût ;
    • éventuellement des noms contenant des accents.

    Utiliser un codage largement reconnu comme UTF-8 facilite les échanges entre systèmes.

    14. Un petit test d'interopérabilité

    Imaginez que vous deviez transmettre votre fichier CSV à un conseiller utilisant un autre logiciel.

    Avant l'envoi, vérifiez :

    • que la première ligne contient des noms de champs compréhensibles ;
    • qu'une ligne correspond à un seul enregistrement ;
    • que le séparateur utilisé est connu ;
    • que le codage est UTF-8 ;
    • que les dates utilisent toutes la même convention ;
    • que les unités sont connues ;
    • qu'aucune donnée inutile n'a été ajoutée ;
    • que la source est indiquée lorsqu'une donnée extérieure est intégrée.

    À retenir

    • Le format d'une donnée influence sa capacité à être échangée et réutilisée.
    • CSV est un format texte simple particulièrement adapté à l'échange de données tabulaires.
    • Le séparateur, le codage des caractères, les dates et les unités doivent être connus pour importer correctement les données.
    • L'interopérabilité permet à des logiciels différents de travailler avec les mêmes données.
    • Une donnée doit être accompagnée de son contexte : signification, unité, source et date.
    • Une donnée ouverte peut être réutilisée dans le respect de sa licence.
    • Choisir un outil numérique, c'est aussi vérifier que l'on pourra récupérer et transférer ses données.

Séance 1 : Bien démarrer en MG1 Informatique

Module MG1 – Informatique

Compétence visée : Prendre en main son environnement numérique et présenter son profil

Objectifs d’apprentissage
    Ce que vous allez découvrir :
  • Le fonctionnement des cours d'informatique cette année.
  • La manière dont vous allez travailler et rendre vos fichiers.
  • Les principales compétences qui seront travaillées au cours de l'année.
  • L'importance de l'autonomie, de l'essai et du droit à l'erreur.
    Ce que vous allez commencer à savoir faire :
  • Créer un dossier de travail correctement organisé.
  • Créer et enregistrer un document avec un nom précis.
  • Retrouver un fichier enregistré.
  • Modifier simplement la présentation d'un document.
  • Présenter quelques informations de manière claire et organisée.

1. Bienvenue en MG1 Informatique

Cette année, les cours d'informatique ne consisteront pas seulement à apprendre où se trouvent les boutons d'un logiciel.

Vous allez surtout apprendre à utiliser l'ordinateur pour résoudre des problèmes, organiser des informations, traiter des données et présenter des résultats.

Au cours de l'année, nous utiliserons notamment :

  • LibreOffice Calc pour organiser et traiter des données ;
  • différents outils numériques pour rechercher et exploiter des informations ;
  • des fichiers provenant de situations professionnelles ;
  • des tableaux et des graphiques ;
  • des outils permettant de communiquer ou de présenter des résultats.

La plupart du temps, vous apprendrez en faisant.

2. Comment allons-nous travailler ?

En informatique, il est normal de ne pas savoir immédiatement comment réaliser quelque chose.

Vous aurez le droit :

  • d'essayer ;
  • de vous tromper ;
  • d'annuler une action ;
  • de recommencer ;
  • de chercher une solution ;
  • de demander de l'aide ;
  • d'aider un camarade sans faire le travail à sa place.

Une erreur n'est donc pas un problème.

Ce qui est important, c'est de chercher à comprendre comment la corriger.

3. Le document de travail

Dans la plupart des séances, vous travaillerez dans un fichier qui sera créé dès le début du cours.

Ce fichier pourra servir :

  • de brouillon ;
  • d'espace pour essayer ;
  • pour répondre aux questions ;
  • pour réaliser les exercices ;
  • pour conserver certaines explications ;
  • pour montrer votre progression pendant la séance.

À la fin du cours, le fichier demandé devra être rendu.

Un fichier incomplet mais contenant votre travail vaut mieux qu'un fichier qui n'est pas rendu.

Avant de travailler ensemble pendant l'année, prenons quelques minutes pour nous présenter.

Il n'y a pas de bonne ou de mauvaise réponse.

Cette présentation sert simplement à mieux connaître le groupe et à adapter les activités de l'année.

6. Pourquoi bien ranger ses fichiers ?

Imaginez un ordinateur contenant plusieurs centaines de fichiers portant les noms suivants :

  • document1.odt
  • nouveau.odt
  • copie.odt
  • truc.odt
  • final.odt
  • final2.odt
  • final_vraiment.odt

Quelques semaines plus tard, retrouver le bon document devient très difficile.

Un fichier doit donc avoir un nom permettant de savoir rapidement :

  • à qui il appartient ;
  • à quel cours il correspond ;
  • ce qu'il contient.

Séance 2 : Comprendre ce que racontent les données

Module MG1 – Informatique

Compétence visée : Étudier un phénomène à l'aide de données

Objectifs d’apprentissage
    Ce que vous allez apprendre :
  • Une donnée est une valeur brute que l'on observe, mesure ou enregistre.
  • Une information est obtenue lorsque l'on donne du sens à une ou plusieurs données.
  • Une donnée doit être accompagnée de son contexte pour être correctement comprise.
  • Un tableau permet d'organiser plusieurs données pour pouvoir les comparer et les analyser.
  • Les données peuvent être de différentes natures : texte, nombre, date, catégorie, etc.
  • Un tableur comme Calc permet de traiter rapidement une grande quantité de données.
    Ce que vous allez apprendre à faire :
  • Créer et enregistrer correctement un classeur Calc.
  • Identifier les différentes données présentes dans un tableau.
  • Retrouver une information à partir de plusieurs données.
  • Effectuer quelques calculs simples dans un tableur.
  • Utiliser des données pour répondre à une question professionnelle.

1. Créez votre document de travail

Ouvrez LibreOffice Calc et créez un nouveau classeur.

Enregistrez immédiatement votre fichier dans votre dossier MG1_INFORMATIQUE sous le nom :

BACPRO1_S02_nom_prenom.ods

Pensez ensuite à enregistrer régulièrement avec Ctrl + S.

Ce classeur sera votre document de travail pendant toute la séance : vous pourrez y écrire, essayer, vous tromper, modifier et recommencer.

2. Une structure équestre produit-elle des données ?

Une structure équestre produit et utilise chaque jour de nombreuses données.

Par exemple :

  • le nom des chevaux ;
  • leur âge ;
  • leur poids estimé ;
  • la quantité de fourrage distribuée ;
  • leur activité ;
  • les dates de soins ou d'interventions ;
  • le nombre de cavaliers ;
  • les stocks disponibles ;
  • les dépenses et recettes de la structure.

Tous ces éléments peuvent devenir des données lorsqu'ils sont enregistrés.

L'IFCE (Institut Français du Cheval et de l'Équitation) rappelle par exemple que connaître le poids vif d'un cheval (son poids sur pied, animal vivant) est utile pour établir une ration, suivre sa croissance ou son état et adapter certains traitements.

Les données ont donc une utilité concrète dans le fonctionnement d'une entreprise.

Sources professionnelles :

  • IFCE – équipédia : Estimation du poids.
  • IFCE – équipédia : Les besoins alimentaires du cheval.
  • Chlorofil – Document d'accompagnement du module MG1 du Bac professionnel.

Les chevaux et les relevés utilisés dans cette activité sont fictifs. Les valeurs ont été adaptées pédagogiquement à partir de références professionnelles afin de proposer une situation réaliste. Elles ne constituent pas des recommandations individuelles d'alimentation.

3. Une donnée sans contexte est-elle vraiment utile ?

Observez la donnée suivante :

520

Que signifie ce nombre ?

  • 520 € ?
  • 520 kg ?
  • 520 chevaux ?
  • 520 heures ?
  • 520 litres ?

Sans contexte, il est impossible de savoir ce que cette valeur représente réellement.

Si nous écrivons maintenant :

Volcan – poids estimé : 520 kg

la donnée devient compréhensible.

Nous connaissons :

  • ce qui est mesuré : le poids ;
  • l'animal concerné : Volcan ;
  • la valeur : 520 ;
  • l'unité : kg.

4. Donnée ou information ?

Retenez cette différence importante :

  • Donnée : valeur brute observée, mesurée ou enregistrée.
  • Information : résultat obtenu lorsque l'on interprète une ou plusieurs données dans un contexte.

Exemple :

Donnée : 15

Donnée avec son contexte : Java a 15 ans.

Si nous comparons maintenant cette donnée avec l'âge de tous les autres chevaux :

Information : Java est le cheval le plus âgé du groupe.

Pour produire cette information, il a fallu réaliser un traitement : comparer plusieurs données.

Les quantités de foin ont été adaptées pour être cohérentes avec les ordres de grandeur présentés par l'IFCE.

L'IFCE indique notamment que la quantité de fourrage dépend du poids vif, de l'activité, de l'état corporel et des caractéristiques du fourrage.

Un exemple donné par l'IFCE montre qu'un cheval de 500 kg consommant l'équivalent de 1,5 % de son poids vif en matière sèche représente environ 9 kg brut de foin avec un foin à 85 % de matière sèche.

Les valeurs du tableau sont des données pédagogiques fictives et simplifiées. Elles ne doivent pas être utilisées pour établir la ration réelle d'un cheval.

  • adapter la largeur des colonnes ;

  • afficher correctement les nombres décimaux ;
  • rendre le tableau facile à lire.

Vous êtes libre de choisir la présentation.

Le but n'est pas de faire le tableau le plus décoré possible mais le plus lisible possible.

  3. Quel est l'âge moyen des huit chevaux ?
  4. Quel est leur poids estimé moyen ?

Vous pouvez réaliser les calculs comme vous le souhaitez.

Sinon, cherchez une méthode permettant d'obtenir le résultat.

9. À quoi sert réellement le tableur ?

Avec seulement huit chevaux, il est encore possible d'observer le tableau et de réaliser certains calculs manuellement.

Imaginez maintenant un fichier comportant :

  • 80 chevaux ;
  • 500 clients ;
  • 365 jours de relevés ;
  • plusieurs milliers de lignes de données.

Effectuer tous les calculs manuellement deviendrait beaucoup plus difficile.

C'est l'un des rôles d'un tableur.

Un tableur permet notamment de :

  • stocker des données ;
  • les organiser ;
  • effectuer automatiquement des calculs ;
  • trier et filtrer les données ;
  • rechercher certaines valeurs ;
  • créer des graphiques ;
  • comparer des résultats ;
  • aider à prendre une décision.

10. Toutes les données se ressemblent-elles ?

Observez les différentes colonnes du tableau.

Elles ne contiennent pas toutes le même type de données.

Exemple Ce que représente la donnée Type

520 Poids estimé Nombre
9,2 Quantité de foin Nombre décimal
01/09/2026 Date d'un relevé Date

Le type d'une donnée est important car il détermine les traitements que l'ordinateur pourra effectuer.

Par exemple :

  • on peut calculer la moyenne des poids ;
  • on peut classer des dates dans l'ordre chronologique ;
  • on peut compter le nombre de chevaux appartenant à une catégorie ;
  • mais calculer la moyenne des noms des chevaux n'aurait aucun sens.

11. Données, traitement, information

Le travail réalisé aujourd'hui peut être résumé par trois étapes :

DONNÉES → TRAITEMENT → INFORMATION

Exemple 1 :

  • Données : les âges des huit chevaux.
  • Traitement : comparer les âges.
  • Information : Java est le cheval le plus âgé.

Exemple 2 :

  • Données : les quantités de foin distribuées aux huit chevaux.
  • Traitement : additionner les valeurs.
  • Information : 71,5 kg de foin sont distribués chaque jour.

Exemple 3 :

  • Données : les poids estimés des huit chevaux.
  • Traitement : calculer leur moyenne.
  • Information : le poids estimé moyen du groupe est d'environ 505,6 kg.

Pour vous aider, relisez les informations données par l'IFCE : la quantité de fourrage dépend notamment du poids, de l'activité, de l'état corporel et des caractéristiques du fourrage.

À retenir

Séance 3 : Peut-on faire confiance à toutes les données ?

  • Une cellule doit contenir une seule valeur.

  • Une donnée douteuse ne doit jamais être corrigée au hasard.
  • Les données originales doivent être conservées avant toute modification.
    Ce que vous allez apprendre à faire :
  • Repérer des erreurs dans un jeu de données.
  • Identifier différents types de données.
  • Uniformiser des textes, des nombres et des dates.
  • Repérer et supprimer un doublon.
  • Signaler une donnée manquante ou douteuse.

2. Situation professionnelle

Une structure équestre enregistre régulièrement des informations concernant les chevaux présents dans son écurie.

  • son nombre d'heures de travail par semaine ;
  • son statut actuel.

Ces données pourraient ensuite servir à suivre les animaux, préparer des calculs, observer une évolution ou aider le responsable de la structure à prendre certaines décisions.

Mais le fichier a été complété par plusieurs personnes et toutes n'ont pas utilisé les mêmes méthodes de saisie.

Votre mission : rendre ce fichier propre et exploitable sans inventer de données.

Sources professionnelles utilisées pour construire l'activité :

5. Comment organiser correctement des données ?

Pour qu'un tableau soit facilement exploitable par un ordinateur, nous allons respecter trois règles simples :

  • Une ligne = une observation.
  • Une colonne = une information.
  • Une cellule = une valeur.

Exemple :

Cheval Poids estimé (kg) Foin distribué (kg/jour)
Volcan 520 10

Il est préférable d'écrire 10 dans la cellule plutôt que 10 kg.

L'unité kg/jour est déjà indiquée dans le titre de la colonne.

Calc pourra ainsi reconnaître la valeur comme un nombre et l'utiliser directement dans des calculs.

7. Mission : uniformisez les textes

Travaillez maintenant uniquement dans DONNEES_NETTOYEES.

Observez la colonne Cheval.

Première lettre en majuscule, autres lettres en minuscules.

Faites ensuite de même avec la colonne Statut.

Les seules valeurs utilisées seront :

  • Actif

  • Soins

Vous pouvez modifier les cellules une par une ou rechercher une méthode permettant de remplacer plusieurs valeurs rapidement.

Indice : cherchez la fonction Rechercher et remplacer.

8. Mission : remettez les nombres au propre

Observez les colonnes :

  • Poids estimé (kg) ;
  • Foin distribué (kg/jour) ;
  • Travail par semaine (h).

Ces colonnes doivent contenir uniquement des nombres.

Corrigez les cellules contenant directement une unité, par exemple :

11 kg → 11

Vérifiez également les valeurs décimales.

Elles doivent être reconnues par Calc comme de véritables nombres et non comme du texte.

9. Mission : uniformisez les dates

Une même date peut être écrite de plusieurs manières :

  • 05/09/2026
  • 5/9/26
  • 05-09-2026
  • 5 septembre 2026

Pour une personne, ces écritures peuvent représenter la même information.

Pour un tableur, certaines peuvent être reconnues comme des dates et d'autres comme du texte.

Dans cette activité, toutes les dates devront être de véritables dates Calc et être affichées sous la forme :

JJ/MM/AAAA

Exemple :

05/09/2026

Uniformisez toutes les dates du tableau.

11. Mission : une donnée semble anormale

Une ligne du fichier indique un poids estimé de :

52 kg

Cette valeur est très différente des autres observations du fichier.

L'IFCE rappelle que le poids vif est notamment utilisé pour établir une ration, suivre l'état d'un cheval ou adapter certains traitements.

Il est donc particulièrement important que cette donnée soit fiable.

Quelle solution vous semble la plus professionnelle ?

  1. Remplacer automatiquement 52 par 520.
  2. Supprimer la ligne.
  3. Conserver temporairement la valeur et signaler qu'elle doit être vérifiée.
  4. Retrouver le relevé original pour contrôler la valeur avant de la modifier.

Expliquez votre choix dans la feuille DIAGNOSTIC.

Une donnée surprenante n'est pas automatiquement une donnée fausse.

Si vous ne disposez pas de la source originale, vous ne connaissez pas la bonne valeur.

12. Une référence professionnelle peut-elle corriger une donnée ?

L'IFCE indique que la quantité de fourrage distribuée dépend notamment du poids vif et précise des ordres de grandeur exprimés en pourcentage de ce poids.

Une référence professionnelle peut donc nous aider à détecter qu'une valeur mérite d'être vérifiée.

Mais peut-elle nous permettre de connaître automatiquement la vraie valeur contenue dans le relevé original ?

13. Mission : cherchez le doublon

14. Contrôlez votre fichier

Avant de terminer, vérifiez votre feuille DONNEES_NETTOYEES.

Elle doit respecter les règles suivantes :

  • chaque ligne correspond à une observation ;
  • les noms des chevaux utilisent la même présentation ;
  • les statuts sont uniquement Actif, Repos ou Soins ;
  • les colonnes numériques contiennent uniquement des nombres lorsque la donnée est connue ;
  • les unités sont indiquées dans les titres et non dans les cellules ;
  • les dates utilisent le même format et sont reconnues comme des dates ;
  • les données manquantes sont signalées ;
  • les données douteuses sont signalées et non inventées ;
  • le doublon a été supprimé ;
  • la feuille DONNEES_BRUTES est toujours intacte.

15. Pourquoi nettoyer les données ?

Imaginez maintenant que l'on demande à Calc de calculer :

  • le poids moyen des chevaux ;
  • la quantité totale de foin distribuée ;
  • le nombre de chevaux actifs ;
  • l'évolution du poids d'un cheval au cours du temps.

Si certaines données sont enregistrées comme du texte, dupliquées, manquantes ou incorrectes, les résultats peuvent être faux.

L'ordinateur peut effectuer un calcul parfaitement juste à partir de données incorrectes et produire malgré tout une conclusion fausse.

La qualité d'une analyse dépend donc aussi de la qualité des données utilisées.

Dans votre feuille DIAGNOSTIC, répondez avec vos propres mots :

  1. Pourquoi faut-il nettoyer les données avant de les analyser ?
  2. Pourquoi faut-il conserver les données originales ?
  3. Que faut-il faire lorsqu'une donnée semble fausse mais que l'on ne connaît pas la bonne valeur ?
  4. Quelle différence faites-vous maintenant entre une donnée anormale et une donnée fausse ?

À retenir

  • Des données doivent être organisées, cohérentes et vérifiables avant d'être analysées.
  • Une ligne = une observation.
  • Une colonne = une information.
  • Une cellule = une valeur.
  • Les nombres doivent rester des nombres : les unités sont de préférence indiquées dans les titres de colonnes.
  • Les formats doivent être cohérents dans l'ensemble du tableau.
  • Un doublon peut fausser les résultats d'une analyse.
  • Une donnée manquante ne doit pas être inventée.
  • Une donnée inhabituelle doit être contrôlée avant d'être corrigée.
  • Une source professionnelle peut aider à détecter une incohérence mais ne permet pas forcément de retrouver la vraie valeur.
  • Il est important de conserver les données brutes avant toute modification.
  • Une correction doit pouvoir être justifiée et tracée.

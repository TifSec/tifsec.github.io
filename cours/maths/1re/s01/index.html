Séance 1 — Développer, résoudre ax + b = c, appliquer une formule

Trois notions : développer et factoriser, résoudre ax + b = c, appliquer une formule. Pour chacune : la notion, la méthode, l’exemple au tableau, puis les exercices.

I. Développer et factoriser

La notion

Développer, c’est transformer un produit en somme : 3(x + 4) devient 3x + 12.

Factoriser, c’est l’inverse : 5x + 10 devient 5(x + 2).

À retenir

k(a + b) = ka + kb.

Comment ça fonctionne

  1. Développer : multiplie le nombre devant la parenthèse par chaque terme de la parenthèse.
  2. Factoriser : cherche le nombre qui divise tous les termes, et sors-le devant la parenthèse.
  3. Contrôle : en redéveloppant, tu dois retrouver l’expression de départ.

Pourquoi ça marche

1. Avec une situation

  • 3 chevaux reçoivent chacun x kg de foin et 4 kg de granulés : 3 × (x + 4).
  • C’est aussi 3 fois x kg de foin plus 3 fois 4 kg : 3x + 12.

2. Avec des nombres

  • 3 × (10 + 4) = 3 × 14 = 42.
  • 3 × 10 + 3 × 4 = 30 + 12 = 42 : même résultat.

II. Résoudre ax + b = c

La notion

Résoudre une équation, c’est trouver la valeur de x qui rend l’égalité vraie.

Pour ax + b = c, on défait les calculs dans l’ordre inverse.

À retenir

ax + b = c → ax = c − b → x = (c − b) ÷ a.

Comment ça fonctionne

  1. Enlève b des deux côtés (ou ajoute-le s’il est négatif).
  2. Divise les deux côtés par a.
  3. Écris x = …
  4. Contrôle : remplace x dans l’équation de départ.

Pourquoi ça marche

1. La balance

  • Une égalité est comme une balance en équilibre.
  • Si on fait la même opération des deux côtés, elle reste en équilibre.

2. Défaire dans l’ordre inverse

  • Pour fabriquer 3x + 5, on a fait × 3 puis + 5.
  • Pour retrouver x, on fait − 5 puis ÷ 3.

Exercices (calculatrice autorisée)

Donne la valeur de x.

  1. Série A — 2x + 3 = 11. x = ?
  2. 5x + 10 = 45. x = ?
  3. 4x − 6 = 18. x = ?
  4. 3x + 7 = 7. x = ?
  5. Série B — 12x + 50 = 170. x = ?
  6. 0,5x + 2 = 9. x = ?
  7. Une pension coûte 50 € + 12 € par jour. Combien de jours pour 230 € ? (12x + 50 = 230) (en jours)

III. Appliquer une formule

La notion

Une formule donne un résultat à partir de valeurs connues (prix, quantité, durée…).

On remplace chaque lettre par sa valeur, puis on calcule.

À retenir

Remplacer les lettres, puis calculer en respectant les priorités.

Comment ça fonctionne

  1. Recopie la formule.
  2. Remplace chaque lettre par sa valeur (avec son unité dans ta tête).
  3. Calcule : × et ÷ avant + et −.
  4. Écris le résultat avec son unité.

Pourquoi ça marche

1. Ce qu’est une formule

  • C’est un calcul qu’on refait souvent, écrit une fois pour toutes avec des lettres.
  • Coût = 50 + 12 × j veut dire : 50 € fixes plus 12 € par jour.

2. Pourquoi les priorités

  • 12 × j doit être fait avant d’ajouter 50.
  • 50 + 12 × 10 = 170, pas 620.

Exemple fait ensemble en classe

Exercices (calculatrice autorisée)

Calculatrice autorisée.

  1. Série A — C = 50 + 12 × j. Calcule C pour j = 10. (en €)
  2. Ration R = 0,02 × P (P en kg). Calcule R pour P = 550. (en kg)
  3. Aire A = L × l. Calcule A pour L = 40 m et l = 25 m. (en m²)
  4. Prix TTC = HT × 1,2. Calcule pour HT = 85 €. (en €)
  5. Série B — Vitesse v = d ÷ t. Calcule v pour d = 36 km et t = 3 h. (en km/h)
  6. Coût C = 2,5 × q + 18. Calcule C pour q = 12. (en €)

Encore des exercices (si tu as fini)

  1. 6(x + 2) = 6x + ?
  2. 9x + 27 = 9(x + ?)
  3. 7x − 4 = 31. x = ?
  4. C = 2,5 × q + 18 = 68. q = ?

À retenir

  • Développer : k(a + b) = ka + kb.
  • Factoriser : ka + kb = k(a + b).
  • ax + b = c → x = (c − b) ÷ a.
  • Formule : on remplace chaque lettre par sa valeur, puis on respecte les priorités.

Séance 1 : Bienvenue en technologie

Objectif de la séance

Cette première séance va permettre de découvrir la manière dont nous allons travailler cette année en technologie.

Vous allez régulièrement devoir :

  • observer ;
  • chercher ;
  • faire des hypothèses ;
  • tester vos idées ;
  • vous tromper parfois ;
  • corriger et améliorer votre travail ;
  • expliquer vos choix.

Le but n’est pas de connaître immédiatement toutes les bonnes réponses, mais d’apprendre à chercher et à progresser.

1. Créer votre premier document de travail

Cette année, presque chaque séance commencera de la même manière : vous créerez immédiatement votre document de travail.

Créez maintenant un document LibreOffice Writer nommé :

Remplacez nom par votre nom.

Commencez votre document en indiquant :

  • votre nom et votre prénom ;
  • la date ;
  • le titre : Séance 1 : Bienvenue en technologie.

Ce document doit être créé dès le début du cours.

Il pourra servir à la fois :

  • de brouillon ;
  • de carnet de recherche ;
  • d’espace pour vos essais ;
  • de fichier de réponses ;
  • de trace de votre travail.

Vous n’avez donc pas besoin d’attendre d’avoir une réponse parfaite avant d’écrire.

2. À quoi sert votre fichier ?

À la fin de presque chaque séance, vous devrez rendre le fichier sur lequel vous avez travaillé.

Le fichier doit être rendu même s’il n’est pas terminé.

Il permettra au professeur de voir :

  • ce que vous avez essayé ;
  • les idées que vous avez proposées ;
  • les difficultés rencontrées ;
  • les corrections effectuées ;
  • votre implication pendant le cours ;
  • votre progression au fil de l’année.

Au début de l’année, vos documents pourront être simples et parfois désordonnés.

Au fil des séances, vous devrez apprendre à les rendre progressivement plus clairs, mieux organisés et plus agréables à lire.

3. Peut-on se tromper ?

Oui.

En technologie, une réponse incorrecte peut être très intéressante si elle montre une véritable réflexion.

Vous aurez souvent le droit de :

  • proposer une idée sans être certain qu’elle fonctionne ;
  • faire un essai ;
  • obtenir un résultat inattendu ;
  • modifier votre réponse ;
  • recommencer autrement.

Lorsque vous modifiez une réponse après une recherche, une expérience ou une discussion, cela montre que votre réflexion progresse.

Une réponse imparfaite mais expliquée est préférable à une réponse parfaite copiée sans réflexion.

4. Comment demander de l’aide ?

Le professeur est là pour vous aider à avancer, mais il ne donnera pas systématiquement la solution.

Avant de demander de l’aide, essayez :

  1. de relire la consigne ;
  2. d’observer les informations disponibles ;
  3. de tester une première idée ;
  4. de rechercher si cela est autorisé ;
  5. éventuellement d’échanger avec un camarade.

Vous pouvez ensuite expliquer au professeur :

« J’ai essayé ceci, j’ai obtenu cela, mais je bloque ici. »

Cette manière de demander de l’aide est beaucoup plus utile que :

« Je ne comprends rien. »

5. Seul ou avec les autres ?

Vous travaillerez souvent seul sur votre poste informatique.

Certaines activités pourront cependant être réalisées à plusieurs.

Même lorsque vous travaillez seul, vous pourrez parfois :

  • échanger une idée avec un camarade ;
  • comparer vos résultats ;
  • demander un avis ;
  • expliquer votre raisonnement à quelqu’un.

Ces échanges doivent rester calmes afin de permettre à chacun de travailler.

Les discussions à voix basse sont possibles lorsqu’elles servent le travail.

6. Ce qui sera évalué cette année

Votre travail ne sera pas évalué uniquement sur le nombre de bonnes réponses.

Le professeur observera régulièrement :

  • votre implication ;
  • votre envie de chercher ;
  • votre autonomie ;
  • votre capacité à tester une idée ;
  • votre capacité à expliquer votre raisonnement ;
  • votre capacité à corriger et améliorer votre travail ;
  • la progression de vos productions numériques ;
  • votre comportement pendant le travail.

Les fichiers rendus au fil des séances permettront donc de suivre votre progression sur la durée.

Compétence visée

Ce que vous allez apprendre à faire :

  • observer et comparer plusieurs solutions techniques ;
  • formuler une hypothèse avant de rechercher une réponse ;
  • identifier ce que fait l’utilisateur et ce que fait l’objet ;
  • vérifier une hypothèse avec une source technique ;
  • justifier l’évolution d’un objet technique.

8. Mettons des mots sur ce que nous avons découvert

Les différents objets étudiés répondent globalement au même besoin : nettoyer un sol.

Pourtant, leurs usages, leurs avantages, leurs limites et la quantité de travail laissée à l’utilisateur sont différents.

Les objets et systèmes techniques évoluent notamment lorsque :

  • les besoins ou les habitudes évoluent ;
  • les utilisateurs recherchent davantage de confort ou d’autonomie ;
  • de nouvelles technologies deviennent disponibles ;
  • de nouvelles contraintes apparaissent.

Une évolution technique ne rend donc pas automatiquement une solution meilleure dans toutes les situations.

  • construire une chronologie simple ;

  • présenter des informations de manière plus organisée dans un document numérique.

    1. Introduction

    Avant de pouvoir concevoir ou modifier un système automatisé, il est essentiel de comprendre comment les instructions logiques guident son comportement.
    La carte Micro:bit permet de visualiser concrètement ce lien entre le code et l’action : un petit programme devient immédiatement observable (lumière, son, mouvement).

    Comment un robot sait-il quoi faire ? Comment décide-t-il d’avancer ou de tourner ?
    Le robot ne décide pas, il suit des instructions programmées à l’avance.
    Pour que le robot avance, évite un mur, ou retourne à sa base, il exécute un programme.
    Nous allons découvrir comment on crée ces instructions avec une carte Micro:bit.

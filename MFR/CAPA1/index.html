Séance 1 — Faire connaissance et prendre ses repères

Cette première séance permet de découvrir le fonctionnement du cours d'informatique, de prendre ses repères sur l'ordinateur et de faire quelques premières manipulations.

1. Bienvenue en informatique

Cette année, nous allons apprendre à utiliser l'ordinateur et les outils numériques dans des situations utiles pour votre formation, vos stages, votre futur métier et votre vie quotidienne.

Vous allez surtout pratiquer. Vous aurez le droit d'essayer, de vous tromper, de recommencer et de demander de l'aide.

Le but n'est pas de tout savoir immédiatement, mais de devenir progressivement plus autonome.

2. Notre fonctionnement

  • Au début de chaque séance, vous créez ou ouvrez votre document de travail.
  • Ce document sert de cours, de brouillon, de zone d'essai et de feuille de réponses.
  • Vous l'enregistrez régulièrement pendant la séance.
  • Vous rendez votre fichier à la fin du cours, même s'il n'est pas terminé.
  • Vous pouvez demander de l'aide, mais vous devez d'abord essayer.

3. Créer votre espace de travail

Aller dans le dossier "Documents"

Créer un nouveau dossier nommé : "Nom_prénom" (avec votre nom et votre prénom)

Entrer dans ce dossier puis créez un dossier nommé :

MG1_INFORMATIQUE

Dans ce dossier, créez un nouveau dossier :

SEANCE_01

Ouvrez ensuite LibreOffice Writer et créez un nouveau document.

Enregistrez-le immédiatement dans le dossier SEANCE_01 avec le nom :

CAPA1_S01_nom_prenom.odt

4. Faisons connaissance

Dans votre document, écrivez le titre :

Ma fiche de présentation

Puis répondez tranquillement aux questions suivantes avec quelques mots ou quelques phrases.

  1. Quel est votre prénom ?
  2. Pourquoi avez-vous choisi cette formation ?
  3. Quel métier ou domaine professionnel vous intéresse aujourd'hui ?
  4. Avez-vous déjà effectué un stage ou travaillé dans ce domaine ?
  5. Utilisez-vous souvent un ordinateur ?
  6. Qu'est-ce que vous savez déjà faire sur un ordinateur ?
  7. Qu'est-ce qui vous semble difficile avec un ordinateur ?
  8. Qu'aimeriez-vous apprendre cette année ?

Il n'y a pas de mauvaise réponse. Cette fiche sert simplement au professeur à mieux vous connaître et à adapter les prochaines séances.

5. Première petite mission

Améliorez maintenant légèrement votre document.

  • Agrandissez le titre.
  • Mettez le titre en gras.
  • Choisissez une présentation claire pour vos réponses.
  • Mettez au moins un mot important en gras.

Pendant votre travail, pensez à utiliser régulièrement :

  • Ctrl + S pour enregistrer ;
  • Ctrl + Z pour annuler la dernière action en cas d'erreur.

6. Avant de terminer

Vérifiez que votre fichier porte bien le nom :

CAPA1_S01_nom_prenom.odt

Enregistrez une dernière fois votre travail puis rendez votre fichier selon la méthode indiquée par le professeur.

Le fichier doit être rendu même s'il n'est pas terminé.

Séance 2 — Ranger et retrouver ses fichiers

Un ordinateur peut contenir des milliers de fichiers. Aujourd'hui, nous allons apprendre à les ranger pour pouvoir les retrouver facilement.

1. Préparer le document de la séance

Ouvrez votre dossier :

MG1_INFORMATIQUE

Créez à l'intérieur un nouveau dossier nommé :

SEANCE_02

Ouvrez LibreOffice Writer puis enregistrez immédiatement votre document dans ce dossier sous le nom :

CAPA1_S02_nom_prenom.odt

Écrivez ensuite le titre :

Séance 2 — Ranger et retrouver ses fichiers

2. Fichier ou dossier ?

Un dossier sert à ranger et organiser des éléments.

Un fichier contient généralement un travail : texte, image, photographie, vidéo, tableau, PDF...

Dans votre document, recopiez puis complétez :

  • Un dossier sert à...
  • Un fichier sert à...
  • Le fichier que je suis en train de modifier s'appelle...
  • Il est enregistré dans le dossier...

3. Mission : préparer votre espace professionnel

Imaginez que vous allez utiliser votre ordinateur pendant toute votre formation et vos périodes de stage.

Dans votre espace personnel, créez un dossier nommé :

CAPA1

À l'intérieur, créez les trois dossiers suivants :

01_COURS
02_STAGES
03_DOCUMENTS

Dans le dossier 02_STAGES, créez ensuite :

ENTREPRISE
PHOTOS
DOCUMENTS_STAGE

4. Pourquoi ranger ?

Dans votre document de travail, répondez aux questions suivantes.

  1. Pourquoi est-il utile de créer plusieurs dossiers ?
  2. Pourquoi les noms comme document1, nouveau document ou truc ne sont-ils pas de bons noms de fichiers ?
  3. Proposez un bon nom pour un compte-rendu de stage réalisé en octobre 2026.

5. Petite manipulation

Dans le dossier DOCUMENTS_STAGE, créez un nouveau document Writer.

Enregistrez-le sous le nom :

fiche_stage.odt

Écrivez simplement :

  • Nom de la structure de stage :
  • Commune :
  • Activité principale :
  • Métier que je souhaite découvrir :
  • Une chose que j'aimerais apprendre pendant mon stage :

Si vous ne connaissez pas encore votre lieu de stage, vous pouvez écrire À compléter.

Enregistrez puis fermez le fichier.

Essayez ensuite de le retrouver et de l'ouvrir à nouveau en passant par vos dossiers.

6. Votre arborescence

Dans votre document de séance, reproduisez l'organisation des dossiers que vous venez de créer :

CAPA1
├── 01_COURS
├── 02_STAGES
│   ├── ENTREPRISE
│   ├── PHOTOS
│   └── DOCUMENTS_STAGE
└── 03_DOCUMENTS

Pour faire une barre verticale, utilisez le caractère pipe (|) avec la combinaison de touches Alt Gr + 6.

Entourez ou mettez en gras le dossier dans lequel se trouve fiche_stage.odt.

7. À retenir

  • Je donne un nom clair à mes fichiers.
  • Je range mes fichiers dans des dossiers adaptés.
  • Je vérifie où j'enregistre mon travail.
  • J'utilise Ctrl + S régulièrement.
  • Je dois être capable de retrouver un fichier après l'avoir fermé.

8. Rendu

Enregistrez une dernière fois votre document :

CAPA1_S02_nom_prenom.odt

Rendez-le selon la méthode indiquée par le professeur.

Le fichier doit être rendu même s'il est incomplet.

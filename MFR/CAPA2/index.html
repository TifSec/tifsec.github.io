Séance 1 — Découverte du cours de TIM et prise en main

Objectifs de la séance

  • Comprendre le fonctionnement du cours de TIM cette année.
  • Faire le point sur son expérience avec les outils numériques.
  • Créer et organiser son espace de travail.
  • Créer, enregistrer et retrouver un document.
  • Utiliser les principales fonctions d'un traitement de texte.
  • Exporter un document au format PDF.

1. Présentation du cours de TIM

Cette année, le cours de TIM sera principalement basé sur la pratique.

Vous utiliserez les outils numériques pour réaliser des activités proches de situations que vous pouvez rencontrer dans votre vie quotidienne ou professionnelle : organiser des documents, suivre des informations concernant des chevaux, réaliser des tableaux, préparer des plannings, rechercher des informations, envoyer des documents ou encore communiquer avec une entreprise.

Pendant les séances, vous aurez régulièrement des missions à réaliser.

Le principe est simple :

  • vous essayez ;
  • vous avez le droit de vous tromper ;
  • vous cherchez une solution ;
  • vous demandez de l'aide lorsque vous en avez besoin ;
  • vous améliorez progressivement votre travail.

Le but n'est pas de tout savoir immédiatement, mais de devenir progressivement plus autonome avec un ordinateur.

2. Faisons connaissance

Avant de commencer, nous allons prendre quelques minutes pour discuter de votre expérience et de votre projet.

Réfléchissez notamment aux questions suivantes :

  • Qui êtes-vous ?
  • D'où venez-vous ?
  • Pourquoi avez-vous choisi la MFR de Saint-Flour ?
  • Où avez-vous réalisé votre dernier stage ?
  • Dans quel type de structure avez-vous travaillé ?
  • Quelles étaient vos principales activités ?
  • Qu'aimez-vous particulièrement dans le travail avec les chevaux ?
  • Qu'est-ce qui vous semble le plus difficile ?
  • Que souhaitez-vous faire après votre CAP ?
  • Quels outils numériques avez-vous vus ou utilisés pendant vos stages ?

3. Comment allons-nous travailler ?

Au début de la plupart des séances, vous créerez un document de travail.

Ce document pourra servir :

  • de cahier ;
  • de brouillon ;
  • pour répondre aux questions ;
  • pour faire des essais ;
  • pour conserver une trace de vos manipulations.

Ce document sera généralement rendu à la fin du cours.

Il n'a pas besoin d'être parfait pour être rendu. Un travail incomplet permet également de voir ce que vous avez essayé et les difficultés que vous avez rencontrées.

4. Mission : préparer votre espace de travail

Nous allons commencer par organiser votre espace personnel afin de pouvoir retrouver facilement votre travail pendant toute l'année.

Consigne

Dans votre espace personnel, créez un dossier nommé :

nom_prenom

À l'intérieur de ce dossier, créez un sous-dossier nommé :

CAPA2_TIM

À l'intérieur de ce dossier, créez les trois dossiers suivants :

  • 01_Cours
  • 02_Travaux
  • 03_Documents

Dans le dossier 02_Travaux, créez ensuite un dossier nommé :

S01

Vous utiliserez ce dossier pour enregistrer votre travail d'aujourd'hui.

5. Mission : présenter votre expérience avec les chevaux

Ouvrez LibreOffice Writer et créez un nouveau document.

Enregistrez immédiatement votre document dans le dossier S01 sous le nom :

CAPA2_S01_NOM_Prenom

Votre document va vous permettre de vous présenter tout en réalisant quelques premières manipulations.

Partie 1 — Moi et les chevaux

Ajoutez le titre :

Mon expérience dans le monde du cheval

Puis rédigez quelques phrases pour présenter :

  • votre expérience avec les chevaux ;
  • ce que vous aimez particulièrement faire ;
  • une activité avec laquelle vous êtes maintenant à l'aise ;
  • une activité que vous trouvez encore difficile.

Partie 2 — Mon dernier stage

Ajoutez un sous-titre puis présentez votre dernier stage.

Indiquez au minimum :

  • le nom ou le type de structure ;
  • sa localisation ;
  • les principales activités réalisées ;
  • une tâche que vous êtes maintenant capable de réaliser seul.

Partie 3 — Mon projet

Ajoutez un nouveau sous-titre et expliquez en quelques lignes ce que vous aimeriez faire après votre CAP.

Vous pouvez parler :

  • de la poursuite de vos études ;
  • d'un métier qui vous intéresse ;
  • d'un projet professionnel ;
  • ou simplement de ce que vous aimeriez découvrir.

6. Mission : améliorer votre document

Votre document contient maintenant des informations. Il faut le rendre plus facile et plus agréable à lire.

Votre document doit comporter :

  • un titre clairement identifiable ;
  • au moins deux sous-titres ;
  • du texte en gras ;
  • une liste à puces ;
  • un tableau ;
  • une image correctement dimensionnée.

Créer le tableau

Ajoutez un tableau contenant les informations suivantes :

Information Réponse
Type de structure
Nombre approximatif de chevaux
Activité principale
Durée du stage

Ajouter une image (vous pouvez utiliser les liens ci-dessous, si vous le souhaitez)

  • Cheval 1
  • Cheval 2
  • Cheval 3
  • Centre équestre 1
  • Centre équestre 2

Ajoutez dans votre document une image représentant un cheval ou une structure équestre.

L'image doit être suffisamment grande pour être visible, mais elle ne doit pas prendre toute la page.

Attention : votre document doit rester lisible et correctement organisé.

7. Mission : enregistrer et retrouver son travail

Lorsque votre document est terminé :

  1. enregistrez-le ;
  2. fermez LibreOffice Writer ;
  3. retrouvez votre fichier dans votre dossier S01 ;
  4. ouvrez à nouveau le document ;
  5. modifiez une phrase ;
  6. enregistrez à nouveau votre travail.

Vous devez être capable de retrouver votre document sans avoir besoin de le recréer.

8. Mission : créer une version PDF

Votre document doit maintenant être transformé en PDF.

Exportez votre travail afin d'obtenir deux fichiers :

  • CAPA2_S01_NOM_Prenom.odt
  • CAPA2_S01_NOM_Prenom.pdf

Les deux fichiers doivent se trouver dans votre dossier S01.

9. Défi — Pour ceux qui ont terminé

Si vous avez terminé toutes les missions précédentes, ouvrez LibreOffice Calc.

Reproduisez le tableau suivant :

Cheval Âge Ration matin Ration soir Ration quotidienne
Volcan 12 2 2
Jazz 8 2,5 2,5
Nala 16 1,5 2

Essayez ensuite de trouver comment faire calculer automatiquement la ration quotidienne de chaque cheval.

Essayez avant de demander la solution. Vous avez le droit de tester plusieurs méthodes.

10. Rendu du travail

Avant de quitter votre poste, vérifiez que votre fichier porte bien le nom demandé.

Le fichier à rendre est :

CAPA2_S01_NOM_Prenom.pdf

Avant de rendre votre travail, vérifiez également que :

  • votre document possède un titre ;
  • les différentes parties sont clairement visibles ;
  • votre tableau est complété ;
  • votre image est correctement dimensionnée ;
  • vous avez enregistré votre document original ;
  • vous avez créé la version PDF.

11. Bilan de la séance

Avant de terminer, réfléchissez quelques instants :

  • Qu'est-ce qui vous a semblé facile aujourd'hui ?
  • Qu'est-ce qui vous a posé problème ?
  • Y a-t-il quelque chose que vous aimeriez apprendre à faire avec un ordinateur cette année ?

Ce premier travail ne sert pas à vérifier si vous savez déjà tout faire. Il permet surtout de voir ce que vous maîtrisez déjà et ce que nous devrons travailler ensemble cette année.

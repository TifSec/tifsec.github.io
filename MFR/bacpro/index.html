Séance 1 : Bien démarrer en MG1 Informatique

Module MG1 – Informatique

Compétence visée : Prendre en main son environnement numérique et présenter son profil

Objectifs d’apprentissage
    Ce que vous allez découvrir :
  • Le fonctionnement des cours d'informatique cette année.
  • La manière dont vous allez travailler et rendre vos fichiers.
  • Les principales compétences qui seront travaillées au cours de l'année.
  • L'importance de l'autonomie, de l'essai et du droit à l'erreur.
    Ce que vous allez commencer à savoir faire :
  • Créer un dossier de travail correctement organisé.
  • Créer et enregistrer un document avec un nom précis.
  • Retrouver un fichier enregistré.
  • Modifier simplement la présentation d'un document.
  • Présenter quelques informations de manière claire et organisée.

1. Bienvenue en MG1 Informatique

Cette année, les cours d'informatique ne consisteront pas seulement à apprendre où se trouvent les boutons d'un logiciel.

Vous allez surtout apprendre à utiliser l'ordinateur pour résoudre des problèmes, organiser des informations, traiter des données et présenter des résultats.

Au cours de l'année, nous utiliserons notamment :

  • LibreOffice Calc pour organiser et traiter des données ;
  • différents outils numériques pour rechercher et exploiter des informations ;
  • des fichiers provenant de situations professionnelles ;
  • des tableaux et des graphiques ;
  • des outils permettant de communiquer ou de présenter des résultats.

La plupart du temps, vous apprendrez en faisant.

2. Comment allons-nous travailler ?

En informatique, il est normal de ne pas savoir immédiatement comment réaliser quelque chose.

Vous aurez le droit :

  • d'essayer ;
  • de vous tromper ;
  • d'annuler une action ;
  • de recommencer ;
  • de chercher une solution ;
  • de demander de l'aide ;
  • d'aider un camarade sans faire le travail à sa place.

Une erreur n'est donc pas un problème.

Ce qui est important, c'est de chercher à comprendre comment la corriger.

3. Le document de travail

Dans la plupart des séances, vous travaillerez dans un fichier qui sera créé dès le début du cours.

Ce fichier pourra servir :

  • de brouillon ;
  • d'espace pour essayer ;
  • pour répondre aux questions ;
  • pour réaliser les exercices ;
  • pour conserver certaines explications ;
  • pour montrer votre progression pendant la séance.

À la fin du cours, le fichier demandé devra être rendu.

Un fichier incomplet mais contenant votre travail vaut mieux qu'un fichier qui n'est pas rendu.

4. Avant de commencer : faisons connaissance

Avant de travailler ensemble pendant l'année, prenons quelques minutes pour nous présenter.

À votre tour, indiquez simplement :

  • votre prénom ;
  • votre formation ou votre projet professionnel ;
  • ce que vous aimeriez faire plus tard, si vous le savez déjà ;
  • votre niveau avec un ordinateur : débutant, moyen ou à l'aise ;
  • une chose que vous savez déjà faire sur ordinateur ;
  • une chose que vous aimeriez apprendre à faire.

Il n'y a pas de bonne ou de mauvaise réponse.

Cette présentation sert simplement à mieux connaître le groupe et à adapter les activités de l'année.

5. Première mission : préparer son espace de travail

Nous allons maintenant commencer à travailler sur les ordinateurs.

Dans votre espace personnel, créez un dossier nommé :

nom_prenom

Puis à l'intérieur de ce dossier, créez un sous-dossier nommé :

TIM

À l'intérieur de ce dossier, créez un nouveau dossier :

SEANCE_01

Vous devez obtenir l'organisation suivante :

TIM
        └── SEANCE_01

Nous utiliserons cette organisation pendant l'année afin de retrouver facilement les fichiers.

6. Pourquoi bien ranger ses fichiers ?

Imaginez un ordinateur contenant plusieurs centaines de fichiers portant les noms suivants :

  • document1.odt
  • nouveau.odt
  • copie.odt
  • truc.odt
  • final.odt
  • final2.odt
  • final_vraiment.odt

Quelques semaines plus tard, retrouver le bon document devient très difficile.

Un fichier doit donc avoir un nom permettant de savoir rapidement :

  • à qui il appartient ;
  • à quel cours il correspond ;
  • ce qu'il contient.

7. Votre premier fichier

Ouvrez maintenant LibreOffice Writer.

Créez un nouveau document puis enregistrez-le immédiatement dans le dossier SEANCE_01.

Le fichier doit être nommé :

BACPRO1_S01_nom_prenom.odt

Remplacez évidemment nom et prenom par vos informations.

Exemple :

BACPRO1_S01_dupont_lea.odt

8. Petite vérification

Fermez maintenant votre document.

Retrouvez-le dans votre dossier puis ouvrez-le à nouveau.

Si vous avez réussi, vous venez déjà de réaliser plusieurs opérations importantes :

  • créer une arborescence de dossiers ;
  • enregistrer un fichier à un endroit précis ;
  • respecter une convention de nommage ;
  • retrouver un document enregistré.

9. Mission : créez votre fiche de présentation

Dans votre document Writer, créez maintenant une petite fiche permettant de vous présenter.

Votre fiche doit comporter au minimum :

  • un titre ;
  • votre prénom ;
  • votre projet professionnel ou le métier qui vous intéresse ;
  • votre expérience avec les ordinateurs ;
  • les logiciels ou outils numériques que vous connaissez déjà ;
  • une chose que vous aimez faire ;
  • une chose que vous aimeriez apprendre en informatique cette année.

Vous pouvez ajouter d'autres informations si vous le souhaitez.

Ne mettez aucune information personnelle que vous ne souhaitez pas partager.

10. Première manipulation de mise en forme

Votre document doit maintenant être organisé afin qu'il soit agréable à lire.

Essayez de réaliser les opérations suivantes :

  • agrandir le titre ;
  • mettre le titre en gras ;
  • créer au moins deux sous-titres ;
  • utiliser une liste à puces ;
  • mettre au moins une information importante en gras ;
  • modifier l'alignement d'un élément ;

Vous pouvez tester différentes possibilités.

Si le résultat ne vous plaît pas, utilisez :

Ctrl + Z

Ce raccourci permet d'annuler la dernière action.

11. Petit défi : peut-on apprendre sans tutoriel ?

Ajoutez maintenant une ligne horizontale ou une bordure permettant de séparer deux parties de votre document.

Cette fois, aucune procédure détaillée n'est donnée.

Vous pouvez :

  • chercher dans les menus ;
  • tester différentes commandes ;
  • observer les icônes ;
  • demander un indice ;
  • échanger avec un camarade.

L'objectif n'est pas d'aller vite.

L'objectif est de chercher comment réaliser quelque chose que vous ne savez pas encore faire.

12. Petite enquête pour préparer l'année

À la fin de votre document, ajoutez le titre :

Mon niveau en informatique

Puis recopiez les éléments suivants et indiquez pour chacun :

Je sais faire / Je pense savoir faire / Je ne sais pas encore faire

  • Créer un dossier.
  • Retrouver un fichier sur un ordinateur.
  • Renommer un fichier.
  • Utiliser une clé USB.
  • Créer un document Writer ou Word.
  • Créer un tableau.
  • Utiliser Calc ou Excel.
  • Faire un calcul dans Calc ou Excel.
  • Créer un graphique.
  • Envoyer un fichier en pièce jointe.
  • Trouver une information fiable sur Internet.
  • Utiliser un espace de stockage en ligne.

Ces réponses ne sont pas une évaluation.

Elles serviront à savoir ce que le groupe maîtrise déjà et ce qu'il faudra davantage travailler cette année.

13. Avant de rendre votre travail

Vérifiez les points suivants :

  • Mon fichier est enregistré dans le bon dossier.
  • Le nom du fichier respecte la consigne.
  • Ma fiche comporte un titre.
  • Les informations sont organisées.
  • J'ai essayé plusieurs outils de mise en forme.
  • J'ai répondu à la petite enquête.
  • J'ai enregistré une dernière fois avec Ctrl + S.

À retenir

  • Un fichier bien nommé est beaucoup plus facile à retrouver.
  • Les dossiers permettent d'organiser son travail.
  • Il est conseillé d'enregistrer son document dès le début d'une activité.
  • Ctrl + S permet d'enregistrer rapidement.
  • Ctrl + Z permet d'annuler la dernière action.
  • En informatique, essayer et se tromper font partie de l'apprentissage.

Travail à rendre

À la fin de la séance, déposez le fichier :

BACPRO1_S01_nom_prenom.odt

Le fichier doit être rendu même s'il n'est pas terminé.

Séance 2 : Comprendre ce que racontent les données

Module MG1 – Informatique

Compétence visée : Étudier un phénomène à l'aide de données

Objectifs d’apprentissage
    Ce que vous allez apprendre :
  • Une donnée est une valeur brute que l'on observe, mesure ou enregistre.
  • Une information est obtenue lorsque l'on donne du sens à une ou plusieurs données.
  • Un tableau permet d'organiser plusieurs données pour pouvoir les comparer et les analyser.
  • Les données peuvent être de différentes natures : texte, nombres, dates, réponses oui/non, etc.
  • Un tableur comme Calc permet de traiter rapidement une grande quantité de données.
    Ce que vous allez savoir faire :
  • Créer et enregistrer correctement un classeur Calc.
  • Identifier les différentes données présentes dans un tableau.
  • Retrouver une information à partir de plusieurs données.
  • Effectuer quelques recherches simples dans un tableau.
  • Commencer à utiliser Calc pour répondre à une question professionnelle.

1. Créer le document de la séance

Ouvrez LibreOffice Calc et créez un nouveau classeur.

Enregistrez immédiatement votre fichier dans votre dossier de travail sous le nom :

BACPRO1_MG1_donnees_nom_prenom.ods

Votre fichier doit être enregistré dès le début de la séance. Pensez ensuite à l'enregistrer régulièrement avec Ctrl + S.

Ce classeur sera votre document de travail pendant toute la séance : vous pourrez y écrire, essayer, vous tromper, modifier et recommencer.

2. Une écurie produit-elle des données ?

Imaginez une structure équestre.

Chaque jour, de nombreuses informations peuvent être enregistrées :

  • le nom des chevaux ;
  • leur âge ;
  • leur poids ;
  • la quantité de nourriture distribuée ;
  • leur nombre d'heures de travail ;
  • les dépenses de la structure ;
  • le nombre de cavaliers ;
  • les dates des soins ou interventions ;
  • les stocks disponibles.

Tous ces éléments peuvent devenir des données.

Mais une donnée seule ne nous apprend pas forcément grand-chose.

Par exemple :

520

Que signifie ce nombre ?

520 € ? 520 kg ? 520 chevaux ? 520 heures ?

Sans contexte, cette donnée est difficile à interpréter.

Si l'on écrit :

Volcan – poids estimé : 520 kg

la donnée possède maintenant un contexte et devient beaucoup plus utile.

3. Donnée ou information ?

Retenez cette différence importante :

  • Donnée : valeur brute observée, mesurée ou enregistrée.
  • Information : résultat obtenu lorsque l'on interprète une ou plusieurs données dans un contexte.

Exemple :

Donnée : 15

Donnée avec son contexte : Java a 15 ans.

Information obtenue après comparaison : Java est le cheval le plus âgé de l'écurie.

Pour obtenir cette dernière information, il a fallu comparer l'âge de Java avec celui des autres chevaux.

4. Première mission : observer des données

Dans votre classeur Calc, renommez la première feuille :

DONNEES

Reproduisez le tableau suivant :

Cheval Âge Poids estimé (kg) Travail par semaine (h) Foin par jour (kg) Coût mensuel alimentation (€)
Volcan 12 520 5 10 245
Oslo 8 480 3 9 218
Java 15 540 2 11 263
Nestor 7 505 6 10 251
Praline 10 455 4 8 207
Quartz 6 510 5 10 239
Rivage 13 565 3 12 276
Salsa 9 470 6 9 224

5. Organiser correctement son tableau

Avant de commencer l'analyse, prenez quelques minutes pour améliorer votre tableau.

Vous devez essayer de :

  • mettre les titres des colonnes en évidence ;
  • adapter la largeur des colonnes ;
  • aligner correctement les données ;
  • afficher correctement les valeurs en euros ;
  • rendre le tableau facile à lire.

Vous êtes libre de choisir la présentation.

Le but n'est pas de faire le tableau le plus décoré possible mais celui dans lequel les données sont les plus faciles à comprendre.

6. Que peut-on apprendre grâce à ces données ?

Ajoutez une nouvelle feuille à votre classeur et nommez-la :

ANALYSE

Copiez les questions suivantes puis répondez-y.

  1. Combien de chevaux sont présents dans le tableau ?
  2. Quel est le cheval le plus âgé ?
  3. Quel est le cheval le plus jeune ?
  4. Quel cheval possède le poids estimé le plus élevé ?
  5. Quel cheval travaille le plus d'heures par semaine ?
  6. Quel cheval consomme le plus de foin chaque jour ?
  7. Quel cheval possède le coût mensuel d'alimentation le plus important ?
  8. Quel est le coût mensuel d'alimentation le moins important ?

Pour l'instant, utilisez la méthode de votre choix.

Vous pouvez observer le tableau, faire un calcul, utiliser une fonction de Calc si vous en connaissez déjà une ou essayer de découvrir comment faire.

Vous n'avez pas besoin de connaître toutes les fonctions de Calc pour réussir cette activité.

7. Une question un peu plus difficile

Répondez maintenant aux questions suivantes :

  1. Quelle quantité totale de foin faut-il prévoir chaque jour pour les huit chevaux ?
  2. Combien cela représente-t-il approximativement pour 30 jours ?
  3. Quel est le coût total mensuel de leur alimentation ?
  4. Quel est l'âge moyen des chevaux de cette écurie ?

Vous pouvez faire les calculs comme vous le souhaitez.

Si vous connaissez déjà certaines fonctions de Calc, vous pouvez les utiliser.

Sinon, cherchez une méthode qui vous permet d'obtenir le résultat.

8. Calculer à la main ou utiliser le tableur ?

Imaginez maintenant que le tableau comporte :

  • 80 chevaux ;
  • 500 clients ;
  • 365 jours de consommation ;
  • plusieurs milliers de dépenses.

Effectuer tous les calculs manuellement deviendrait très long.

C'est justement l'un des rôles d'un tableur.

Un tableur permet notamment de :

  • stocker des données ;
  • les organiser ;
  • effectuer automatiquement des calculs ;
  • trier et filtrer les données ;
  • rechercher certaines valeurs ;
  • créer des graphiques ;
  • aider à prendre une décision.

9. Toutes les données ne sont pas identiques

Dans notre tableau, observez les différentes colonnes.

On rencontre plusieurs types de données.

Exemple Type de donnée
Volcan Texte
12 Nombre entier
520 Nombre
245 € Nombre associé à une unité monétaire
01/09/2026 Date
Oui / Non Valeur logique ou catégorie

Le type d'une donnée est important car il détermine ce que l'ordinateur pourra en faire.

Par exemple, Calc peut calculer une moyenne avec des âges, mais pas avec des noms de chevaux.

10. Donnée, traitement, information

Le travail réalisé aujourd'hui peut être résumé très simplement :

DONNÉES → TRAITEMENT → INFORMATION

Exemple :

  • Données : les âges de tous les chevaux.
  • Traitement : comparer les valeurs.
  • Information : Java est le cheval le plus âgé.

Autre exemple :

  • Données : les quantités de foin distribuées chaque jour.
  • Traitement : additionner les valeurs.
  • Information : l'écurie doit prévoir une certaine quantité de foin chaque jour.

11. Votre première conclusion

Dans la feuille ANALYSE, ajoutez le titre :

Ce que j'ai compris aujourd'hui

Puis complétez avec vos propres mots les trois phrases suivantes :

  1. Une donnée est...
  2. Une information est...
  3. Un tableur peut être utile dans une entreprise parce que...

Il n'est pas nécessaire de recopier exactement le cours. Expliquez ce que vous avez compris avec vos mots.

À retenir

  • Une donnée est une valeur brute observée, mesurée ou enregistrée.
  • Une donnée n'a de sens que si l'on connaît son contexte.
  • Une information est obtenue après avoir interprété une ou plusieurs données.
  • Les données peuvent être du texte, des nombres, des dates ou différentes catégories.
  • Un tableur permet d'organiser et de traiter rapidement de nombreuses données.
  • Analyser des données consiste à les utiliser pour répondre à une question.

Travail à rendre

À la fin de la séance, déposez le fichier :

BACPRO1_MG1_donnees_nom_prenom.ods

Votre fichier doit contenir au minimum :

  • une feuille DONNEES avec le tableau correctement reproduit et présenté ;
  • une feuille ANALYSE avec vos réponses aux questions ;
  • les quatre calculs demandés ;
  • votre conclusion personnelle.

Le fichier doit être rendu même si tout n'est pas terminé.
